# WayBlog 需求说明

## 目标

WayBlog 是一个单管理员使用的个人博客系统，重点解决以下问题：

- 低成本管理文章内容
- 公开展示文章、分类和标签页
- 支持 Markdown 写作和基本 SEO
- 提供简单的后台统计和友链管理

## 用户角色

### 访客

- 浏览首页文章列表
- 阅读文章详情
- 按分类、标签、归档浏览文章
- 使用搜索查找文章
- 查看关于页和友链页

### 管理员

- 登录后台
- 管理文章、分类、标签、友链
- 上传图片
- 查看站点统计

## 功能范围

### 内容管理

- 文章支持草稿和发布状态
- 文章支持置顶
- 文章支持摘要、封面、分类和多个标签
- 文章内容使用 Markdown 存储

### 前台展示

- 首页分页展示已发布文章
- 文章详情页渲染 Markdown
- 分类页和标签页支持分页
- 归档页按年月分组
- 搜索页支持关键字查询

### 后台管理

- 后台登录页
- 文章管理页
- 分类管理页
- 标签管理页
- 友链管理页
- 统计仪表盘

### 平台能力

- 图片本地上传
- 亮色 / 暗色主题切换
- 基础 SEO 输出
- RSS、sitemap、robots
- 简单限流
- 浏览量统计

## 非目标

当前版本不包含以下能力：

- 多用户注册与权限系统
- 评论系统
- 云对象存储
- 富文本编辑器
- 外部搜索引擎集成

## 约束

- 仅支持单管理员模型
- 数据库使用 PostgreSQL
- 图片默认保存在本地 `public/uploads`
- 搜索基于全文范围的关键词匹配
- 管理后台依赖登录态访问

## 验收标准

- 管理员可以完成文章、分类、标签、友链的基本 CRUD
- 前台可以稳定浏览和搜索已发布文章
- `pnpm lint` 和 `pnpm build` 可通过
- 未登录用户不能访问后台管理页和受保护写接口
